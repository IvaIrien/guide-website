My Website Style Guide

About This Guide

This is my personal collection of design ideas, colour palettes, CSS styles, and useful code that I can come back to when building websites.

This guide helps me keep my designs consistent, remember important styling rules, and save components and ideas that I like. It also includes useful reminders for layouts such as Flexbox, CSS Grid, spacing, typography, buttons, navigation, and responsive design.

As I learn more about front-end development, I can keep adding new styles, code examples, and design rules — creating my own library of things that work well.
